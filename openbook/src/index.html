      Bienvenue sur OpenBook

      Un clic pour que Windows ressemble à un Googlebook, partout :

      • Thème, couleurs et fond d'écran Material You dans tout Windows
      • Barre des tâches masquée : le dock OpenBook la remplace
      • OpenBook s'ouvre dès le démarrage de Windows
      • Touche Windows : lanceur OpenBook · Win+Tab : Vue d'ensemble
      • Verr. Maj : Quick Insert (Maj + Verr. Maj pour les majuscules)
      • Secoue la souris pour demander à Gemini

      Réversible à tout moment : Paramètres OpenBook → « Revenir à Windows ».
