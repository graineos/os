# Angel OS IA

Angel OS IA is the first distribution built on Angel OS Core. It is the personal AI-oriented layer: agents, model providers, automations, tools and interfaces belong here, not in the Core.

The distribution must remain optional. A third party can reuse Angel OS Core without using Angel OS IA, or replace every AI integration with their own modules.

Planned layers:

- provider adapters for AI models;
- agent registry and permissions;
- automation module;
- tool/connector module;
- optional personal interface;
- audit and safety controls.
